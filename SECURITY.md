# Security Policy

## Supported versions

vPole has not had a stable release yet. Security fixes are made on the `master` branch only.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, pull requests, or discussions.

Report them privately through GitHub: open the repository's **Security** tab and select
**Report a vulnerability**. Include:

- the affected component and version or commit;
- steps to reproduce, or a proof of concept;
- the impact you expect, such as tenant isolation bypass, credential exposure, or code execution;
- any suggested fix or mitigation.

The maintainer aims to acknowledge reports within 7 days and will keep you informed while the issue
is investigated and fixed. Please give a reasonable time to release a fix before disclosing the
issue publicly. vPole has no bug bounty program.
